---
description: Scan all globally installed skills/plugins for available updates
---

Load the `skill-improver` skill and run **Workflow 1: Scan for updates**.

Crawl the user's globally installed plugins and skills, report which have newer
versions available at their source, and offer next steps. Do not modify anything
during the scan — updating is the user's call via `/plugin`.

If the user named a specific skill or plugin, focus the report on that one.
